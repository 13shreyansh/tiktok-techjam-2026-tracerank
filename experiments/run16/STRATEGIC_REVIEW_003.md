# Run 16 fresh-context review — after sparse-FM shadow family

## Does this still advance winning?

Yes, with bounded uncertainty. The 1K port is no longer speculative engineering:
three chronological windows succeeded, forward primary stayed between 0.6250
and 0.6264, runtime stayed under two minutes, and memory stayed under 3 GB. This
is an independent optional organizer benchmark and does not endanger the
protected Pure fallback.

## What could still make it worthless?

- The organizers publish no bonus formula or 1K baseline, so an absolute score
  cannot yet be translated into judging points.
- The hidden-test/checkpoint delivery mechanism is unknown.
- High-activity users have strong GAUC but lower top-five quality; an eventual
  sequential model must improve list heads without sacrificing ordering.
- The current FM uses only five fields and does not exploit the reason the
  dataset recommends 1K: long sequential histories and rich feedback.
