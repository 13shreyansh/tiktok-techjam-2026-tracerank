# Run 14 strategic review 000

The strongest verified gain so far came from within-user rank aggregation, not
from extra model complexity. Median consensus is therefore a focused extension
of demonstrated signal. It is also meaningfully different from weight tuning:
there is one parameter-free robust statistic and a chronological transfer gate.

The risk is that mean rank is statistically more efficient when seed errors are
roughly symmetric; median may throw away useful magnitude and increase ties.
Six missing shadow-seed runs are justified only because all three windows can
then test the same rule before official validation is touched. A mixed or small
result closes the family without trying trimmed means or weights.
