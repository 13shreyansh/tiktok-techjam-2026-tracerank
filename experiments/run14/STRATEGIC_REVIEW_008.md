# Run 14 strategic review 008

Median consensus did not show the consistent advantage required to justify an
official-validation check. It lost the early current window, produced only
sub-threshold middle gains, and slightly regressed low-activity users in both
windows. Because the protocol requires two successful windows out of three,
the late window cannot change the decision.

Stopping now is both the convergence and winning decision. Mean within-user
rank remains the supported aggregation rule. Searching trimmed means, quantiles,
or member weights would convert one clean hypothesis into an open-ended
validation search. No official-validation or public-test result was consumed by
Run 14, and the protected six-member Run 2 fallback remains untouched.
