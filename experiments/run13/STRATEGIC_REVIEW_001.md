# Run 13 strategic review 001

The fixed caption representation produced the pattern the gate was designed to
catch: a forward-window gain alongside a current validation loss and regression
in every activity/date subgroup. The improvement is therefore not reliable
enough to justify additional seeds or windows. The randomized SVD warnings also
make this representation less trustworthy, although the output remained finite.

Stopping after one attempt is the correct winning decision. Changing TF-IDF
vocabulary size, n-grams, SVD width, or scaling after observing this result would
open a large validation-tuning surface. Run 2 remains the strongest verified
official-validation candidate, and Run 13 contributes only an audited official
content resource and a negative experimental result.
